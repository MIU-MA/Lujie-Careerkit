# 发送前质量检查

## 事实

- [ ] 所有候选人经历、技能、数字和结果都来自材料。
- [ ] 到岗时间、实习时长、每周天数、地点和毕业时间均已确认。
- [ ] “参与、协助、负责、主导”的强度没有升级。
- [ ] JD 要求没有被偷换成候选人能力。
- [ ] 公司事实有最新来源，推断已明确标注。
- [ ] 没有替用户编造长期关注、文化认同或梦想加入等动机。

## 匹配

- [ ] 选择的是与岗位最相关的 2—3 个证据，而不是最华丽的经历。
- [ ] 技能后面有项目、任务或结果支撑。
- [ ] 公司背景只保留与岗位和候选人证据有关的内容。
- [ ] 缺口没有被掩盖成已掌握。

## 表达

- [ ] 前两句已经说明关键价值。
- [ ] 没有“本人性格开朗、学习能力强”等无依据模板话。
- [ ] 没有复述完整简历。
- [ ] 没有关键词堆砌、夸张营销话术或过度谦卑。
- [ ] 每句话都在提供匹配证据、岗位理解或下一步行动。

## 渠道

- [ ] 长度、礼貌程度和段落适合发送渠道。
- [ ] 公司名、岗位名、岗位编号、称呼和附件名准确。
- [ ] 招呼语重点在前，正式求职信有完整逻辑。
- [ ] 可直接发送版本中没有分析标签、引用标记和待办说明。

## 最后处理

发现缺失事实时，优先删除无法支撑的句子；只有该事实会显著改善文本时才向用户询问。不要在可直接发送版本中留下 `[公司名]`、`[数字]` 等占位符，除非用户明确要模板。
